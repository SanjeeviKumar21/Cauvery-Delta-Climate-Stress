# Publish in GitHub and LinkedIn

1. Open https://github.com/new and create a **public repository** named `Cauvery-Delta-Climate-Stress`. Select **no auto-generated README** (this package includes one).
2. Open the new repo and choose **uploading an existing file**. Upload the top-level files `README.md`, `analysis.R`, `RESEARCH_REPORT.md`, `DATA_PROVENANCE.md`, `LINKEDIN_POST.md` and the `data` and `outputs` contents. Preserve the directory paths. If GitHub's web uploader does not preserve folders from your system, use **Add file → Create new file** for the path first, or use GitHub Desktop (optional). Do not upload the ZIP as the only repository item.
3. Verify the README images render and the data and script are visible. Use the repository URL in place of the placeholder inside `LINKEDIN_POST.md`.
4. Publish the LinkedIn post with the R-generated `02_aadi_pattam_four_years.png` and (optionally) `05_apr_jun_to_jul_aug.png`.
5. CV portfolio link: `https://github.com/SanjeeviKumar21/Cauvery-Delta-Climate-Stress` **only after the repository exists**. Avoid claiming field-validated predictive models or measured water savings.

Note: The outputs have already been created in the user's RStudio session; you do **not** need to rerun or reinstall anything to share the completed analysis.
